# Breakroom downloads

Download **Breakroom for Mac** to host Local quiz games on your own laptop, with no internet needed. Players join over the same Wi-Fi.

**[Download the latest version](https://github.com/yemiSage/breakroom-downloads/releases/latest)** and choose `Breakroom-macOS.zip`.

Works on Apple-chip and Intel Macs (macOS 12 or newer).

## To open it
1. Unzip `Breakroom-macOS.zip`.
2. Right-click **Breakroom.app** and choose **Open**, then confirm. You only need to do this the first time, because the app is not notarized by Apple.
3. The host screen opens in your browser. Keep the app running until the game ends.

To host over the internet instead, with nothing to install, use Online at https://br.opeyemiadegboye.com.
